Security & Account Safety

Grant Intelligence is designed so users do not enter a password on the Grant Intelligence website.

Passwordless authentication

Account access uses Supabase Authentication and a secure email verification link. You enter only the email address you want associated with your Grant Intelligence account. The verification link is sent to that email account.

What Grant Intelligence will never ask for

Grant Intelligence will never ask you to enter the password for Google, Gmail, GitHub, Supabase, a bank, an employer, or another third-party service. If any page claiming to be Grant Intelligence asks for one of those passwords, do not enter it.

Application credentials

Private application credentials such as Dify API keys and server-side Supabase secrets are not stored in browser JavaScript. They belong in secure server-side configuration such as Supabase Edge Function secrets.

Account access

Use the official Grant Intelligence account page and verify that your browser address bar shows the expected Grant Intelligence website before continuing.
