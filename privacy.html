Privacy Notice

This development-stage privacy notice explains the current Grant Intelligence test environment. It should be reviewed and expanded before public commercial launch.

Free readiness assessment

The free assessment is designed to avoid collecting sensitive personal documents. Assessment information may be saved to a user's Supabase account when the user chooses to create a project.

Account information

Grant Intelligence uses Supabase Authentication for account verification. The current website uses passwordless email-link authentication and does not ask users to create or enter a password on the Grant Intelligence website.

Project information

In Real Test and future Paid modes, project information and later uploaded files may be stored in the user's Supabase workspace and may be sent to configured Dify workflows when the user intentionally runs an analysis module.

Demo mode

Demo mode uses the same account and project infrastructure but does not call Dify for sample module output.
